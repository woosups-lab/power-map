송전선로 (전압별)

지형 정보

지형 정보 선택은 설정 탭의 배경 지도가 ‘항목 선택 지도’일 때 적용됩니다.

송전선로·변전소·발전소는 OpenInfraMap과 같은 OpenStreetMap 데이터입니다. 매주 자동으로 갱신되며, 이 기기에 저장해 두고 새 날짜의 데이터가 나왔을 때만 다시 받습니다.

현장 정보

파일로 한꺼번에 가져오기

구글어스 KML·KMZ, 엑셀에서 저장한 CSV(현장명·주소 또는 위도·경도 열), 이 프로그램에서 내보낸 JSON을 받습니다.

내보내기

현장 정보는 이 기기에만 저장되고 어디로도 전송되지 않습니다. 다른 기기와 맞추려면 JSON으로 내보낸 파일을 그 기기에서 가져오세요. 공개 저장소이므로 내보낸 파일을 저장소에 올리지 마세요.

현장 주변 변전소

주변 변전소는 이 기기에 저장된 데이터로 계산하므로 오프라인에서도 됩니다. 거리는 직선거리입니다. 도로 경로는 OSRM(OpenStreetMap 기반)으로 최대 3개 대안을 보여주며 인터넷이 필요합니다. 실제 교통 반영 길찾기는 각 경로의 ‘카카오맵’ 버튼으로 이어집니다.

배경지도 미리 저장

출장 전에 관심 지역을 저장해 두면 인터넷 없이도 배경지도가 나옵니다. ‘항목 선택 지도’만 저장할 수 있고, 일반 지도·위성 사진은 온라인에서만 보입니다.

저장한 지역

앱으로 설치

윈도우·맥(크롬·엣지)은 주소창 오른쪽의 설치 아이콘, 안드로이드는 메뉴의 ‘홈 화면에 추가’, 아이폰·맥 사파리는 공유 버튼의 ‘홈 화면에 추가’(맥은 ‘Dock에 추가’)로 설치합니다.

주소 검색 정확도

키가 없으면 OpenStreetMap 주소 검색을 씁니다. 한국 지번 주소는 잘 못 찾는 경우가 많아, 카카오 키를 넣는 것을 권합니다. 키를 발급할 때 이 프로그램을 여는 사이트 주소(예: GitHub Pages 주소)를 플랫폼 도메인에 등록해야 합니다.

데이터

현장 정보는 지금 쓰는 브라우저(또는 설치한 앱) 안에 저장됩니다. 브라우저와 설치한 앱의 저장 공간이 다른 기기도 있으니, 기기를 바꾸거나 앱을 지우기 전에 JSON으로 내보내 두세요.
