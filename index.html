지적

지형 정보

지형 정보 선택은 설정 탭의 배경 지도가 ‘항목 선택 지도’일 때 적용됩니다.

송전선로·변전소·발전소는 OpenInfraMap과 같은 OpenStreetMap 데이터입니다. 매주 자동으로 갱신되며, 이 기기에 저장해 두고 새 날짜의 데이터가 나왔을 때만 다시 받습니다.

첨부 파일·사진

현장 정보

파일로 한꺼번에 가져오기

구글어스 KML·KMZ, 엑셀에서 저장한 CSV(현장명·주소 또는 위도·경도 열), 이 프로그램에서 내보낸 JSON·전체 백업(ZIP)을 받습니다.

내보내기

전체 백업 ZIP은 보관용입니다. 암호화되지 않으니 회사 내부에만 보관하고 공개 저장소에는 올리지 마세요. JSON·CSV·KML에는 첨부 파일이 들어가지 않습니다.

현장 주변 변전소

주변 변전소는 이 기기에 저장된 데이터로 계산하므로 오프라인에서도 됩니다. 거리는 직선거리입니다. 도로 경로는 OSRM(OpenStreetMap 기반)으로 최대 3개 대안을 보여주며 인터넷이 필요합니다. 실제 교통 반영 길찾기는 각 경로의 ‘카카오맵’ 버튼으로 이어집니다.

배경지도 미리 저장

출장 전에 관심 지역을 저장해 두면 인터넷 없이도 배경지도가 나옵니다. ‘항목 선택 지도’만 저장할 수 있고, 일반 지도·위성 사진은 온라인에서만 보입니다.

앱으로 설치

윈도우·맥(크롬·엣지)은 주소창 오른쪽의 설치 아이콘, 안드로이드는 메뉴의 ‘홈 화면에 추가’, 아이폰·맥 사파리는 공유 버튼의 ‘홈 화면에 추가’(맥은 ‘Dock에 추가’)로 설치합니다.

주소 검색 정확도

사이트 공통 키가 설정되어 있으면 비워 두어도 됩니다. 여기에 넣은 키는 이 기기에서만 쓰입니다. 키를 발급할 때 사이트 주소를 JavaScript SDK 도메인에 등록해야 합니다.

배경 지도

데이터

현장·기록·첨부는 서버에 저장되어 모든 기기에서 같이 보입니다. 이 기기에도 저장본을 두어 오프라인에서 볼 수 있고, 오프라인에서 고친 내용은 연결되면 서버에 저장됩니다. 서버에는 자동 백업이 없으니 관리자는 가끔 전체 백업 ZIP을 받아 두세요.

전력설비 데이터는 매주 자동으로 갱신됩니다. 시작할 때 새 날짜가 있으면 알아서 받으므로 평소에는 누를 필요가 없습니다.
